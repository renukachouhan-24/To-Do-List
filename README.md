To-Do List App 📝
A simple and interactive To-Do List application built using HTML, CSS, and JavaScript. This app allows users to add, edit, delete, and manage their tasks efficiently.

Features 🚀
✔️ Add Tasks: Easily create and save new tasks.
✏️ Edit Tasks: Modify existing tasks quickly.
❌ Delete Tasks: Remove completed or unnecessary tasks.
🔍 Search Tasks: Filter tasks by specific keywords.
🗂️ Task Categories: Organize tasks into categories for better management.
✅ Mark Tasks as Complete: Track completed tasks with a simple click.
Technologies Used 🛠️
HTML: For the structure of the application.
CSS: For styling and responsiveness.
JavaScript: For interactivity and task management.

Usage 📝
Add Task: Type in the task input field and click the "Add Task" button.
Edit Task: Click the "Edit" button next to any task, modify it, and save.
Search Tasks: Use the search bar to find tasks by keyword.
Mark as Complete: Click the checkbox to mark a task as completed.
